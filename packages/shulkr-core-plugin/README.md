# shulkr-core plugin

Companion Paper plugin for the [shulkr](https://shulkr.dev) panel. Its **only** purpose is to
push verified real-time telemetry to the shulkr backend so the Analytics page can display
accurate data.

**Parity rule:** shulkr must behave identically whether this plugin is installed or not.
The plugin is purely additive, it never replaces any panel mechanism.

## Compatibility

| Platform  | Compiled against                       | Runs on                                    |
| --------- | -------------------------------------- | ------------------------------------------ |
| Paper     | `paper-api` 26.2 (build 127, stable)   | Paper 1.19 to 26.2 on Java 17, 21 or 25    |
| Folia     | same jar as Paper                      | Folia 1.20.x to 26.2                       |
| Velocity  | `velocity-api` 3.3.0                   | Velocity 3.2 to 3.3.x                      |
| Waterfall | `waterfall-api` 1.20                   | Waterfall 1.19 to 1.21.x                   |

Every jar is compiled with `--release 17`, so the same artifact loads on Java 17, 21 and 25
servers. Paper 26.x itself requires Java 25 on the server, the plugin does not add any
requirement on top of that.

## Build

Requires a JDK 25 toolchain: Gradle downloads one automatically through the foojay resolver
when none is installed locally. The wrapper pins Gradle 9.7.1.

```bash
./gradlew build
```

Produces `build/libs/<version>/shulkr-core-<platform>-<version>.jar` for `paper`, `folia`,
`velocity` and `waterfall`, then copies each one to
`packages/backend/dist/assets/plugins/<platform>/shulkr-core-<platform>.jar` (consumed by the
backend installer).

## Manual install

Drop `shulkr-core-paper.jar` into `plugins/` on your Paper server and create
`plugins/shulkr-core/config.yml` with:

```yaml
backend_url: http://your-shulkr-host:3000
server_id: <id shown by the shulkr panel>
token: <token generated by the shulkr panel>
push_interval_seconds: 5
protocol_version: 1
```

Then restart the Minecraft server. Use `/shulkr status` to verify the connection and
`/shulkr reload` after updating the config.

In normal use, prefer the "Install" button in the shulkr panel which handles the copy
and config generation for you.
